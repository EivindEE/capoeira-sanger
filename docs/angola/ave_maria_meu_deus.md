# Ave Maria meu Deus
Ave Maria meu Deus,   
nunca vi casa nova cair   
Nunca vi casa nova cair,   
nunca vi casa nova cair   

_Coro:_  
_Ave Maria meu Deus,_  
_nunca vi casa nova cair_  

Nunca vi angoleiro cair,   
nunca vi angoleiro cair   

_Coro_

Nunca vi o menino cair,   
nunca vi a menina cair   

_Coro_
