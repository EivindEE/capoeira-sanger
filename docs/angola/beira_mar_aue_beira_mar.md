# Beira mar, auê Beira mar
Beira mar, auê Beira mar  
  
_Coro:_  
_Beira mar, auê Beira mar_  
  
Beira mar de yoyo!  
_Coro: É de yoyo_  
Beira mar de yaya!  
_Coro: É de yaya_  
Capoeira de angola  
_Coro: É de yoyo  
É gostoso de jogar  
_Coro: É de yaya  
Beira mar, Beira mar  
_Coro: É de yoyo  
Capoeira vai jogar  
_Coro: É de yaya.

_Coro: Til yaya
